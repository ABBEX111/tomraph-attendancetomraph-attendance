How to Publish Tomraph Freespace App Online

This application is entirely self-contained in a single HTML file with LocalStorage data persistence. You can host it completely free online in under 2 minutes so your staff can access it anywhere from any device!

Method 1: GitHub Pages

  1. Create a free account on GitHub.com.
  2. Create a new repository named tomraph-attendance.
  3. Upload this index.html file to the repository.
  4. Go to Settings → Pages, set source to main branch and Save.
  5. Your app will be live at https://username.github.io/tomraph-attendance!
Visit GitHub

Method 2: Netlify Drop (Easiest)

  1. Save this file on your computer as index.html inside a new folder.
  2. Open app.netlify.com/drop in your web browser.
  3. Drag and drop the folder containing your index.html onto the page.
  4. Netlify instantly generates a live, public URL in 5 seconds!
Go to Netlify Drop

Method 3: Vercel

  1. Log in to Vercel.com.
  2. Click Add New Project and import your GitHub repository.
  3. Keep default settings and click Deploy.
  4. Your app is hosted on Vercel's global CDN with free SSL certificate.
